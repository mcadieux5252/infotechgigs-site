# InfoTechGigs.ai marketing site

Static site hosted on Netlify (project `infotechgigs`). Pages: `index.html`, `privacy.html`, `terms.html`, `thanks.html` (shown after the early access form, which Netlify Forms collects as `early-access`).

`index.html` follows the ProcurementGigs.AI home page layout (procurement-gigs.com) with tech copy and the InfoTechGigs green, and is edited directly. `privacy.html`, `terms.html` and `thanks.html` are still generated by `build.py`, which builds both InfoTechGigs and FinanceGigs from one template; edit the `BRANDS` entry or the template, run `python3 build.py`, and copy those three files for this brand into the repo root.

The SMS consent wording on the home page, privacy policy and terms matches the Twilio toll-free verification. Keep it unchanged unless the verification is updated too.
